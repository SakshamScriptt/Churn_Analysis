# Churn_Analysis
End-to-end Customer Churn Analysis using Python and SQLite. This project covers data extraction, cleaning, and feature engineering with Pandas. It includes EDA with Matplotlib/Seaborn and calculates key business metrics like Churn Rate, ARPU, and Revenue at Risk.
